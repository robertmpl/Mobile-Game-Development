# Inventory

**Left Joystick** - Parent: Canvas, Anchor: Bottom Left, Pivot: x0.5 y0.5, Purpose: Mobile controls for movement and attack.

**Right Joystick** - Parent: Canvas, Anchor: Bottom Right, Pivot: x0.5 y0.5, Purpose: Mobile controls for movement and attack.

**Wave started/ended text** - Parent: Canvas, Anchor: Centre, Pivot: x0.5 y0.5, Purpose: Displays when wave started or has ended. 

**Item notification text** - Parent: Canvas, Anchor: Stretch, Pivot: x0.5 y0.5, Purpose: Notify the user when item is picked up (displays stat increase).

**Health Bar** - Parent: Canvas, Anchor: Centre, Pivot: x0.5 y0.5, Purpose: Displays player's health.

**Score text** - Parent: Canvas, Anchor: Centre, Pivot: x0.5 y0.5, Purpose: Displays player's score.

**Game over screen** - Parent: Canvas, Anchor: Stretch, Pivot: x0.5 y0.5, Purpose: Mobile controls for movement and attack.
